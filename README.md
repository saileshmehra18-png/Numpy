# NumPy Practice

A collection of Jupyter notebooks for learning and practising **NumPy**, the Python library for numerical computing.

## Repository contents

- `phase-1.ipynb`
- `phase-2.ipynb`
- `phase-3.ipynb`

Each notebook records hands-on practice as I work through NumPy concepts.

## Run the notebooks

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies.
4. Launch Jupyter.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install numpy jupyter
jupyter notebook
```

Open a notebook from the repository and run its cells.

## Goal

Build a practical understanding of array-based computing in Python through small examples and exercises.
